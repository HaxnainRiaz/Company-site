# Website Build Brief — Company Marketing Website

## Overview
A complete company marketing website built with Next.js App Router, React 19, TypeScript, and Tailwind CSS.
The company sells:
1. AI Voice & Chat Automation
2. Websites & Admin Dashboards
3. POS & Retail Management Systems
4. SEO & Google Business Profile services
5. Workflow Automation
6. E-commerce Development
7. Mobile App Development
8. Social Media Marketing

## Core Principles
- Truthful, quiet, credible studio website (inspired by bittechnologies.co and fynktech.com, original execution).
- Light surfaces throughout; warm neutrals + low-saturation green/teal primary + terracotta accent.
- Single chosen typography: Instrument Sans Latin normal variable WOFF2.
- No fabricated client names, reviews, awards, staff headshots, phone numbers, or addresses.
- Founder work attributed as founder work; synthetic demos clearly labelled as demonstrations.
- Preview mode active (`isPublicationReady = false`) with clear dev notices until real owner facts and credentials are provided.
